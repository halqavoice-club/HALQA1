# Emoji Assets

Place these 3 image files here:

- `laugh.png`    — 😂 Laughing with tears (the one with hand over face)
- `facepalm.png` — 🤦 Facepalm / angry look with gesture  
- `angry.png`    — 😤 Laughing with tears (big smile version)

These are used by the MicEmojiReaction system in the Voice Club.

If images are missing, the system automatically falls back to Unicode emoji.
